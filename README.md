# Sabana Market Frontend

Frontend estático de Sabana Market. Este proyecto está listo para ser usado como un repositorio independiente.

## Instalación

```bash
cd frontend
npm install
```

## Uso

```bash
npm start
```

El frontend se servirá en `http://localhost:5500`.

## Conexión

El frontend está preparado para conectarse automáticamente al backend en `http://localhost:3000`.
